# Mikail's Kebabhaus

Bestell-App für **Mikail's Kebabhaus** — Döner, Dürüm und Teller, frisch vom Spieß.

## Was du hier machen kannst

- Speisekarte durchstöbern (Döner, Dürüm, Teller, Beilagen, Getränke, Süßes)
- Döner und Dürüm anpassen: Größe, Fleisch, Soße, Salat, Extras
- In den Warenkorb legen
- Abholen oder liefern lassen
- Bestellung bestätigen lassen (bleibt auf dem Gerät)

## Lokal starten

```bash
npm install
npm run dev
```

Öffnet die App unter Port 8080.

## Hinweis

Zahlung an der Theke oder beim Fahrer — bar oder Karte. Kein Login nötig.
